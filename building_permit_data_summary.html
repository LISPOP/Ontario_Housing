Available Building Permit Data

Introduction

The general idea was to see if we can use published building permits to identify local projects of densification to see if respondents in our Ontario 2022 survey who have experienced densification in their neighbourhood differ in their attitudes to housing policy than those who have not.

Of these municipalities, we found good building permit data for Toronto, Ottawa, Mississauga, Hamilton, Burlington, St. Catharine’s and Kitchener. If we took those municipalities, we would have 871 cases, essentially stretching across the GTHA plus Kitchener.

Variables Available by Municipality

One of the problems is that each file collects somewhat different information and stores them with differet variable names. Table 1 summarizes the variables that are available in these building-permit data.

Dates

All municipalities include an “issued date” variable, but only four municipalities (Toronto, Mississauga, Hamilton and Kitchener) have a “completed date”. There are advantages and disadvantages to using both.

on the one hand, going with the “issue date” variable will give us a larger sample size. Plus, having building permits issued might actually spur some NIMBY opposition. I feel like it’s not unfrequent for neighbours to keep an eye on what is happening. But, building permits being issued might not actually mean that the project was actually completed. My own view is that we should start with the completed date variable and see how well we do. That would give us Toronto, Mississauga, Hamilton and Kitchener. There are 684 respondents in those cities.

We may end up throwing some of those away as I think it’s going to make the most sense to restrict the analysis to respondents who are only in low-density neighbourhoods. We don’t really care what tower-dwellers think of densification. The problem revolves around how to get people in low-density neighbourhoods to accept densification.

Some municipalities have building permits that go back to 2017, I don’t think we want to include those. The logic would be that utlimately people would become acclimatized to densification, or more respondents than not will have chosen to move into that neighbourhood. I suggest restricting projects to those that were completed in 2021 or 2022, prior to the campaign.

Residential Units Created

Three of the four cities here (Hamilton excepted) have a variable that encapsulates the number of dwelling units created.

Many of these building permits are in fact permits alterations to structures (think a deck or an interior renovation), but we can’t just throw these away as there are variables in these data sets that describe demolitions as well. And we need to make use of that to find densification projects because, a single family dwelling that is torn down and has a building permit to build a new SFD is not densification. But an existing SFD that is renovated to add a unit is densification. However, just to get a sense of these data, I am going to temporarily exclude any building permits that do not create any units and show some basic summary statistics of what is left.

The scales are really wonky in the distribution because the vast majority of these building permits are for 1 unit, but they do also include permits for a few towers.

So you can see that in these cities, there are some building permits for new houses; we’re going to have to be more particular about identifying densification.

Plus, we have this problem that Hamilton does not actually have these dwelling units created, so we need to rely on qualitative descriptions of projects in the permit type and structure type variables.

Densification flow chart

The table below goes through the flow chart decision by decision and shows which variables each decision uses and what it decides.

Decision Question Variable(s) used What it decides
Q1 Does the city record dwelling units created? municipality Toronto, Mississauga and Kitchener go to Q2; Hamilton goes to Q8.
Q2 Units created at the address units_created_at_address (sum of dwelling_units_created over all non-demolition permits at the same street_address) 0: no new units. More than 6: larger project. 1 to 6: go to Q3.
Q3 Does this permit create units? dwelling_units_created, permit_type Permits that create no units, and demolition permits, are supporting permits and not counted. Permits creating at least one unit go to Q4.
Q4 Is it a multi-unit or added-suite structure? Note: I checked and Toronto, Kitchener and Hamilton uses this variable to record what a building will become after the project. Mississauga secondary suites are caught in the next question using permit_type structure_type Yes: densification (secondary suite, conversion, laneway or garden suite, multiplex). No: go to Q5.
Q5 Does the permit alter or add to an existing building? permit_type Yes: densification (unit added to an existing dwelling). No (new construction): go to Q6.
Q6 Is there a demolition permit at the same address? permit_type, street_address (searched across the full municipal file, any date) Yes: go to Q7. No: unclear, needs a location check.
Q7 Does the address gain more units than the demolition removed? This is an address-level test of the net change in units: units_created_at_address minus the units lost on the demolition permit. It is done at the address rather than the permit because a city may split one project across several permits (e.g., a new house plus a separate laneway-suite permit, or a semi pair on two permits). Toronto (DWELLING_UNITS_LOST) and Kitchener (Units Lost) record units lost on demolition permits; Mississauga does not, so we assume one unit was lost. We also assume at least one unit was lost everywhere, and take the largest value at the address so that revisions of the same demolition are not double counted. units_created_at_address, units_lost_at_address (from the demolition permits at the same street_address) Net gain above 0: densification (teardown replaced by more units). Net gain of 0 or less: replacement with no net gain in units.
Q8 What kind of work? (Hamilton) permit_type (Hamilton’s WORKCLASS), structure_type (Hamilton’s PERMITCLAS) Conversions (Convert Single to Multiple, Convert Multiple to Multiple, Convert NR to Res.): densification (units added by converting an existing building). New Construction of a residential building (Single Family Dwelling or a multi-unit class): go to Q9. Anything else, including non-residential new construction: no evidence of new units.
Q9 Is there a demolition permit at the same address? (Hamilton) permit_type (Full Demolition, Demolish Sgle. Fam., Demolish Multiple Family, Demolition Control; partial, accessory and non-residential demolitions are left out), street_address Yes: go to Q10. No: unclear, needs a location check.
Q10 Does the new building hold more than one unit? (Hamilton) structure_type (Hamilton’s PERMITCLAS) Yes: densification (teardown replaced by more units). Single Family Dwelling: one-for-one replacement.

Diagnostic: Sample of Mild Densification Projects

This applies the flow chart above to each completed permit, then draws a random sample of 10 projects (addresses) per municipality that end in one of the three DENSIFICATION boxes. Every permit at a sampled address that counts as densification is shown, with the branch of the flow chart it came through.

multi_unit_structures<-c(
  # Toronto
  "2 Unit - Detached", "2 Unit - Semi-detached", "2 Unit - Townhouse",
  "3+ Unit - Detached", "3+ Unit - Semi-detached", "3+ Unit - Townhouse",
  "Laneway / Rear Yard Suite", "Converted House", "Duplex", "Triplex/Semi-Detached",
  "Multiple Unit Building", "Apartment Building",
  # Mississauga
  "DUPLEX, 3, 4, 5 0R 6PLEX", "APARTMENT (> 6 UNITS)",
  # Kitchener
  "Duplex Dwelling (2 dwelling units)", "Duplex Dwelling - Condo", "Semi-Duplex Dwelling",
  "Rowhouse Duplex", "Garden Suite", "Apartment")
alteration_permits<-c(
  # Toronto
  "Small Residential Projects", "Building Additions/Alterations",
  # Mississauga
  "ALTERATION TO EXISTING BLDG", "ADDITION AND ALTERATION", "ADDITION TO EXISTING BLDG")
# demolition_permits is defined in the units-per-address-variable chunk

# Hamilton (Q8 to Q10): permit_type is WORKCLASS and structure_type is PERMITCLAS
hamilton_conversions<-c("Convert Single to Multiple", "Convert Multiple to Multiple", "Convert NR to Res.")
# Demolitions that remove a whole building (partial, accessory and
# non-residential demolitions are left out)
hamilton_demolition_permits<-c("Full Demolition", "Demolish Sgle. Fam.", "Demolish Multiple Family", "Demolition Control")
hamilton_multi_unit_structures<-c("Two Family Dwelling", "Three Family Dwelling", "Semi-Detached Dwelling",
                                  "Townhouses", "Townhouse", "Row Dwelling", "Multiple Dwelling", "Apartments")

# Addresses with a demolition permit at any date in the full municipal file,
# with the number of units the demolition removed. Toronto and Kitchener record
# units lost on demolition permits; Mississauga and Hamilton do not. We assume
# at least one unit was lost, and take the largest value at the address rather
# than the sum so that revisions of the same demolition permit are not double
# counted.
units_lost_variable<-c("Toronto"="dwelling_units_lost", "Kitchener"="units_lost")
city.list[c("Toronto", "Mississauga", "Kitchener", "Hamilton")] |>
  imap(\(x, city) {
    lost_values<-if (city %in% names(units_lost_variable)) as.numeric(x[[units_lost_variable[[city]]]]) else NA_real_
    x |>
      mutate(units_lost=lost_values) |>
      filter(permit_type %in% c(demolition_permits, hamilton_demolition_permits)) |>
      group_by(street_address) |>
      summarize(units_lost_at_address=max(c(1, units_lost), na.rm=TRUE))
  }) |>
  bind_rows(.id="municipality") |>
  mutate(demolition_at_address=TRUE)->demolition_addresses

completed |>
  left_join(demolition_addresses, by=c("municipality", "street_address")) |>
  mutate(demolition_at_address=coalesce(demolition_at_address, FALSE),
         # Net change in units at the address (used for Q7)
         net_units_at_address=units_created_at_address-units_lost_at_address,
         densification=case_when(
           # Hamilton branch (Q8 to Q10); Hamilton does not record units created
           municipality=="Hamilton" & permit_type %in% hamilton_conversions ~ "DENSIFICATION: units added by converting an existing building",
           municipality=="Hamilton" & permit_type=="New Construction" & !structure_type %in% c("Single Family Dwelling", hamilton_multi_unit_structures) ~ "No evidence of new units",
           municipality=="Hamilton" & permit_type=="New Construction" & demolition_at_address & structure_type %in% hamilton_multi_unit_structures ~ "DENSIFICATION: teardown replaced by more units",
           municipality=="Hamilton" & permit_type=="New Construction" & demolition_at_address ~ "Replacement: no net gain",
           municipality=="Hamilton" & permit_type=="New Construction" ~ "Unclear: needs location check",
           municipality=="Hamilton" ~ "No evidence of new units",
           # Toronto, Mississauga and Kitchener (Q2 to Q7)
           units_created_at_address==0 ~ "No new units",
           units_created_at_address>6 ~ "Larger project",
           permit_type %in% demolition_permits | !(dwelling_units_created>0) | is.na(dwelling_units_created) ~ "Supporting permit",
           structure_type %in% multi_unit_structures ~ "DENSIFICATION: multi-unit or added-suite structure",
           permit_type %in% alteration_permits ~ "DENSIFICATION: unit added to existing dwelling",
           demolition_at_address & net_units_at_address>0 ~ "DENSIFICATION: teardown replaced by more units",
           demolition_at_address ~ "Replacement: no net gain",
           TRUE ~ "Unclear: needs location check"))->completed

Maps of Densification Projects

These maps show every densification project (address) in Toronto, Mississauga and Kitchener. Mississauga and Kitchener permits come with their own point locations. Toronto permits do not, so they are matched to the City of Toronto address points by street address. Hamilton is left out for now because its permit shapefile has no locations.

# Download Toronto's address points straight from Toronto Open Data
# (https://open.toronto.ca/dataset/address-points-municipal-toronto-one-address-repository/).
# Only the full address and the point are requested, which keeps the download to ~50 MB.
# The geometry column is GeoJSON text, e.g. {"type": "Point", "coordinates": [-79.5, 43.6]}
toronto_address_url<-"https://ckan0.cf.opendata.inter.prod-toronto.ca/datastore/dump/0b3756af-9caf-4f0f-ac28-9c6617adede4?fields=ADDRESS_FULL,geometry&format=csv"
toronto_addresses<-read_csv(toronto_address_url, col_types="cc") |>
  mutate(lon=as.numeric(str_extract(geometry, "(?<=\\[)-?[0-9.]+")),
         lat=as.numeric(str_extract(geometry, "-?[0-9.]+(?=\\])"))) |>
  filter(!is.na(lon), !is.na(lat)) |>
  select(-geometry) |>
  st_as_sf(coords=c("lon", "lat"), crs=4326) |>
  mutate(street_address=str_to_upper(str_squish(ADDRESS_FULL))) |>
  distinct(street_address, .keep_all=TRUE) |>
  select(street_address)

# One point per project (address). An address with permits on more than one

branch_order<-c("teardown replaced by more units", "multi-unit or added-suite structure", "unit added to existing dwelling")

# Toronto: match to the address points. Permits write address ranges
# ("1553-1557 BLOOR ST W"), letter suffixes with a space ("718 R OSSINGTON AVE")
# and split "MC" names ("MC CAUL"); the address points use "1553", "718R" and "MCCAUL"
densification_projects |>
  filter(municipality=="Toronto") |>
  mutate(match_address=street_address |>
           str_replace("^(\\d+)-\\d+ ", "\\1 ") |>
           str_replace("^(\\d+) ([A-Z]) ", "\\1\\2 ") |>
           str_replace(" MC ", " MC")) |>
  inner_join(toronto_addresses, by=c("match_address"="street_address")) |>
  st_as_sf() |>
  select(municipality, street_address, branch)->toronto_points
# Mississauga and Kitchener: one point per address from the permit shapefiles

map_city<-function(city, show_legend=FALSE) {
  points<-filter(project_points, municipality==city)
  ggplot()+
    geom_sf(data=filter(city_boundaries, municipality==city), fill="grey96", colour="grey60", linewidth=0.3)+
    geom_sf(data=points, aes(colour=branch), size=0.6, alpha=0.8, show.legend=show_legend)+
    scale_colour_manual(values=branch_colours, drop=FALSE)+
    guides(colour=guide_legend(override.aes=list(size=3, alpha=1)))+
    labs(title=paste0(city, " (", scales::comma(nrow(points)), " projects)"), colour=NULL)+
    theme_void()
}

Conclusion and concerns

Mostly this works quite well. However, the Hamilton data might be concerning because it does not actually count the number of units created. The category of Convert multiple to multiple might actually include large-scale projects.
